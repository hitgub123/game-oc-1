## 1. 玩家系统

### 1.1 HP（生命值）
- 初始 HP：100
- HP 上限：100
- 头顶 HP 条

### 1.2 命（残机）
- 初始命数：3
- 命上限：**10** 【v2: 5 → v3: 10】
- 命为 0 → GAME_OVER

### 1.3 受伤逻辑
- 玩家被敌人碰触一次 → **扣 40% HP（−40 点）** 【v2: 50% → v3: 40%】
- HP 归零后的处理：
  - **如果有 bomb**：触发防死（消耗所有 bomb，HP=1，不失命）【v3 新增】
  - **如果没有 bomb**：失 1 命，HP 满血复活
- 新生命带炸弹：死亡时记录 `bombsAtDeath`，复活后 `bombs = min(上限, bombsAtDeath + 2)` 【v3.3 新增】

### 1.4 无敌
- 受伤后无敌 1500ms
- 闪烁效果

### 1.5 移动
- WASD 移动，速度 3.5 像素/帧

## 2. 子弹系统

### 2.1 主子弹（始终 1 颗）
- 自动瞄准最近敌人，每 1000ms 发射
- **伤害 = 1** 【v2: 0.5 → v3: 1】
- 颜色：橙红色 `#ff6633`
- 半径 5，速度 5，寿命 120 帧

### 2.2 副子弹（Power 驱动）
- 数量 = `min(4, floor(power))` 【v4: floor(power) → v5: min(4, floor(power))】
- **伤害 = 0.5**
- **速度 = 2.5**（主子弹的一半）【v3.2 新增】
- **每帧追踪最近敌人** 【v3.2: 扇形散射 → v3.2: 追踪】
- **5 种颜色循环**：蓝 `#44aaff` → 青 `#00cccc` → 绿 `#44ff44` → 黄 `#ffcc44` → 紫 `#cc44ff` → 红 `#ff4444` 【v4 新增】

### 2.3 C 键转换
- 按 C 键：如果 power ≥ 1，则 `power -= 1`，`bombs += 1` 【v5 新增】
- power < 1 时无效
- 显示 "-1 POWER → +1 BOMB" 提示
- 主角头上 "x" 爆炸特效

## 3. Power 系统

### 3.1 数值
- 初始：0
- 上限：5
- 每次 +0.1（击杀非 boss 敌人 50% 概率触发）

### 3.2 拾取方式演变
- ~~v2: 缓慢下落，玩家主动捡~~
- ~~v3: 高速自动飞向玩家（5 px/帧）~~
- ~~v3.1: 保持原位，玩家主动捡~~
- **v3.3: 不生成可见道具，击杀时直接 +0.1 power** ← 当前

### 3.3 子机数量
- 子弹数 = `min(4, floor(power))`
- power=0 → 1 主 0 副
- power=1 → 1 主 1 副
- power=4.99 → 1 主 4 副
- power=5 → 1 主 4 副（上限）

### 3.4 C 键转换（v5 新增）
- 按 C 键：power-1, bomb+1
- power<1 时无效

## 5. Bomb 系统

### 5.1 资源
- 初始：2
- 上限：10

### 5.2 主动使用（X/空格）
- 消耗 1 颗
- 发射 20 颗金色子弹（**速度 13.5**【v4: 4.5→v4: 13.5】）
- **对全体敌人造成 2 点伤害**【v2: 清屏→v5: 2点伤害】
- **击杀敌人分数双倍**【v5 新增】
- 玩家获得 1000ms 无敌
- 白闪 + 光环 + "BOMB!" 文字

### 5.3 防死使用（v3 新增）
- 玩家 HP≤0 时，如果有 bomb：
  - 消耗所有 bomb → HP=1 → 失命
  - 触发 Bomb 动画
  - 不算死亡

### 5.4 新生命炸弹（v3.3 新增）
- 死亡复活时：`bombs = min(上限, bombsAtDeath + 2)`

### 6.1 分数

## 9. 音效系统 【v5 新增】

使用 Web Audio API 程序化生成，无需外部文件。

### 音效列表
| 音效 | 触发时机 | 生成方式 |
|------|---------|---------|
| 射击 | 主子弹发射 | 高频方波 ↓ |
| 爆炸 | 敌人死亡 | 白噪声 burst |
| Power | 获得 power | 上升正弦波 |
| Bomb | 使用 bomb | 低频锯齿波 ↓ |
| 受伤 | 玩家被撞 | 低频方波 ↓ |
| Game Over | 游戏结束 | 下降正弦波 |
| Clear | 通关 | 上升和弦 |
| C 键转换 | power→bomb | 短促提示音 |

### 实现
- 创建 AudioContext（用户首次交互后初始化）
- 每个音效独立的 oscillator/gain 节点
- 音量控制，避免爆音
